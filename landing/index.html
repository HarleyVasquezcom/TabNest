TabNest

hive the window, keep the pages

With one click every tab of the current window is stored into a nest — title and URL — and the tabs are closed, freeing memory. Restore one nest or all of them later. Pages are never read: only titles and URLs are recorded, everything lives in local extension storage.

Download ZIP

What it does

  • One click stores every tab of the current window (title + URL) and closes them, so Chrome can release their memory.
  • Each nest shows its saved pages grouped by domain, with a rough estimate of memory freed (≈12 MB per http(s) tab).
  • Restore any nest — tabs reopen — or restore all of them at once.
  • Search nests by name, tab title, URL or domain; delete one nest (two-step) or clear all.
  • The archive keeps the latest 40 nests; internal extension pages are never nested.

Permissions — minimal and used

  • storage — nests and settings live in chrome.storage.local.
  • tabs — reads the window’s tabs (title/URL) when nesting and closes them; reopens them on restore.
  • No host permissions: page content is never touched, nothing is sent anywhere.
Honest note: the memory figure is a deterministic estimate (12 MB per http(s) tab), not a Chrome measurement.

Install

  • Download tabnest.zip and unpack it somewhere permanent.
  • Open chrome://extensions and enable Developer mode.
  • Click “Load unpacked” and pick the folder (keep the folder after loading).
  • Open the popup, nest a window, restore when you need the tabs back.
